# 🌍 WorldFood 3D Adventure

<p align="center"><strong>环游世界 • 发现美食 • 掌握谜题</strong></p>

<p align="center">使用 Kotlin 和 Jetpack Compose 构建的高级 Android Match-3 旅行冒险游戏。</p>

---

## 🎮 关于游戏

**WorldFood 3D Adventure** 将世界探索、国际美食文化和 Match-3 解谜融入一场 Android 冒险。环游风格化的 3D 地球，解锁国家，完成手工设计的关卡，收集星星，发现世界各地的美食。

当前版本包含 **213 个国家**、**3,195 个 Match-3 关卡**（每个国家 15 个）、星星进度、金币、生命值、经验、护照、成就、国家主题音频以及特殊方块和助推器。

## 🌍 地球与旅程

交互式 3D 地球由 **Filament** 引擎驱动。拖动以探索，双指缩放，点击国家标记查看当地美食和进度。搜索系统可以快速找到 213 个国家中的任意一个。

## 🧩 Match-3 玩法

自研引擎支持方块交换、匹配检测、连消、连锁反应、特殊方块、炸弹、彩色炸弹和多种助推器。

## 🛂 进度与护照

游戏进度通过 Android DataStore 保存在设备本地。护照记录旅行目的地、国家印章、每日任务和连续记录。
