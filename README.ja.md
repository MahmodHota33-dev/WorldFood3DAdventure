## 🎮 ゲームについて

**WorldFood 3D Adventure**は、世界探検、国際的な食文化、Match-3パズルをひとつのAndroidアドベンチャーにまとめています。スタイリッシュな3D地球を巡り、国を解放し、手作りのステージをクリアし、星を集め、世界の料理を発見しましょう。

現在の製品版には、**213か国**、**3,195のMatch-3ステージ**（各国15ステージ）、星による進行、コイン、ライフ、XP、パスポート、実績、国をテーマにした音楽、特殊タイルとブースターが含まれます。

## 🌍 地球儀と旅

インタラクティブな3D地球儀は**Filament**エンジンで動作します。ドラッグして探索し、ピンチでズームし、国のマーカーをタップして料理と進行状況を確認できます。検索で213か国をすばやく見つけられます。

## 🧩 Match-3ゲームプレイ

独自エンジンは、タイル交換、マッチ検出、カスケード、連鎖反応、特殊タイル、爆弾、カラーボム、各種ブースターに対応しています。

## 🛂 進行状況とパスポート

ゲームの進行状況はAndroid DataStoreを使って端末にローカル保存されます。パスポートは訪問先、スタンプ、デイリーミッション、連続記録を管理します。
